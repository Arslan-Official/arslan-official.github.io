Custom command-and-control implant

Private research

A C++ implant and loader built for authorised red team simulation against fully patched Windows 11 Pro hosts: Tor-routed C2, modular persistence, and anti-analysis checks. Payloads run in memory with environmental keying, indirect syscalls, and strict RW-to-RX permissions, so no page is ever writable and executable at once. Call stack spoofing hides the origin of those calls from userland hooks.

What survived mattered more than what worked. Defender's cloud protection still flagged the implant, and I traced that to kernel ETW telemetry and scanning of unbacked executable memory rather than to any gap in the userland technique.
